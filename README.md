# 💳 PayFlow

### Smart Payments. Smarter Insights.

PayFlow is a **full-stack digital wallet web application** developed using **Python, Flask, SQLite, HTML, CSS, JavaScript, and Bootstrap**.

The project simulates a digital payment ecosystem where users can securely register and log in, manage their digital wallet, perform transactions, generate QR-based payment requests, and analyze their spending patterns.

---

## 🚀 Key Features

- 🔐 Secure user registration and authentication
- 🔑 Password hashing using Argon2
- 👤 User profile management
- 💰 Digital wallet management
- 💸 Send and receive money simulation
- 📱 QR-based payment simulation
- 📊 Transaction history and expense analytics
- 🔔 User notifications
- 🤖 AI-powered spending insights
- 📈 Monthly spending visualization
- 🛡️ Session management and security controls
- 🗄️ SQLite database integration
- 🔒 Server-side and client-side validation
